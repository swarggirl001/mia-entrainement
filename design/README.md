# Maquettes KalaLab

Brouillons de la nouvelle interface (pas encore dans le site) :
- `accueil.src.html` : l'accueil (clair / sombre, palettes à essayer, objectifs du jour, badges, Kali).
- `icons.js` : les icônes dessinées (à la place des emojis).
- `kali.src.html` et `kali.js` : Kali, l'éléphante mascotte (tenues, entrée sur le logo, passage en cours).

`python3 design/build.py accueil` (ou `kali`) produit la page complète `design/<nom>.html`.

Polices : GLF Cikutra (licence SIL Open Font License 1.1, dans `fonts/`), Bagel Fat One, Pixelify Sans et Lexend (Google Fonts, licence OFL).
